# AdGuard Home и Xray VPN — как они работают вместе

## Как это устроено

```
Устройство → DNS запрос (google.com) → 192.168.1.1:53 (AdGuard Home)
                                              │
                                    Резолвит IP (142.250.x.x)
                                    + Добавляет IP в ipset vpn1
                                              │
Устройство → TCP трафик к 142.250.x.x → iptables
                                              │
                              IP в ipset vpn1? ──── ДА ──→ Redirect к Xray :1080
                                                           → Xray → VPN сервер
                              IP в ipset vpn1? ── НЕТ ──→ Обычный интернет
```

**Ключевая роль AGH**: когда клиент резолвит `google.com`, AGH не только возвращает IP адрес, но и добавляет его в `ipset vpn1`. Дальше iptables перехватывает весь TCP трафик к IP из этого сета и перенаправляет через Xray.

Если AGH не работает или домен не в списке → ipset пустой → трафик идёт напрямую, мимо VPN.

## Настройка для нового роутера

### 1. Установка (install.sh сделает сам)

install.sh устанавливает AdGuard Home и создаёт базовый конфиг. После этого AGH:
- Слушает DNS на порту **53** (`0.0.0.0:53`)
- Веб-интерфейс на порту **3000** (`http://192.168.1.1:3000`)

### 2. Первичная настройка AGH (делается один раз вручную)

Открой `http://192.168.1.1:3000` и пройди мастер настройки:

**Шаг 1 — Интерфейсы:**
- Admin Web Interface: порт `3000`, все интерфейсы (`0.0.0.0`)
- DNS server: порт `53`, все интерфейсы (`0.0.0.0`)

**Шаг 2 — Аутентификация:**
- Задай логин и пароль для веб-интерфейса AGH

**Шаг 3 — Настройка DNS в роутере (критически важно):**

После мастера AGH покажет инструкции. Для Keenetic нужно через SSH:
```sh
ndmc -c "opkg dns-override"
```
Эта команда включает DNS-override — Keenetic начинает пересылать все DNS запросы на `127.0.0.1:53` (AGH).

Проверить что заработало:
```sh
nslookup google.com 127.0.0.1
```
Должен ответить AGH.

**Шаг 4 — Upstream DNS в AGH:**

В AGH веб-интерфейсе → Settings → DNS Settings → Upstream DNS servers:
```
https://dns.cloudflare.com/dns-query
https://dns.google/dns-query
```
Или любой другой надёжный DOH/DOT провайдер. Это то, куда AGH сам будет ходить за резолвингом.

### 3. Проверка ipset

После добавления доменов через наш веб-UI (вкладка «Правила» или «Списки v2fly») и нажатия «Старт», проверь что ipset наполняется:

```sh
# Должны появиться записи после обращения к доменам
ipset list vpn1 | head -10

# Или проверь AGH конфиг — должна быть секция ipset
grep -c 'vpn1' /opt/etc/AdGuardHome/AdGuardHome.yaml
```

## Частые проблемы

### VPN не работает для конкретного домена

1. Проверь что домен добавлен в наш UI (вкладка Домены или v2fly)
2. Убедись что Xray запущен
3. Запроси домен с устройства (сайт откроется), потом проверь ipset:
   ```sh
   ipset list vpn1 | grep <IP_домена>
   ```
4. Если IP не в ipset — AGH не добавил. Перезапусти Xray через UI чтобы обновить конфиг AGH.

### AGH не резолвит / нет интернета

```sh
# Проверь что AGH слушает порт 53
netstat -lnup | grep :53

# Посмотри логи AGH
tail -50 /opt/var/log/AdGuardHome.log

# Перезапусти
/opt/etc/init.d/S99adguardhome restart
```

### `ndmc -c "opkg dns-override"` не помогает

Альтернативный способ — вручную через Keenetic Web UI:
1. Открой `http://192.168.1.1`
2. Управление → Системные настройки → DNS сервер → добавь `127.0.0.1` как первичный

Или через ndmc:
```sh
ndmc -c "ip name-server 127.0.0.1"
```

### Клиенты не получают 192.168.1.1 как DNS

Проверь настройки DHCP Keenetic — он должен раздавать свой LAN IP как DNS:
```sh
ndmc -c "show ip dhcp"
```
В выводе должно быть `dns: 192.168.1.1` (или LAN IP роутера).

## Как наш UI взаимодействует с AGH

При каждом запуске/рестарте Xray через UI (`api.php → start/restart`):

1. `update_adguard_ipset()` — читает все домены из `domains.txt`, ключей v2fly списков
2. Обновляет секцию `ipset:` в `/opt/etc/AdGuardHome/AdGuardHome.yaml`
3. Перезапускает AGH (`reload_adguard()`)

Формат записи в AGH yaml:
```yaml
ipset:
  - google.com/vpn1
  - youtube.com/vpn1
  - ...
```

Это значит: «при резолве google.com — добавь все ответные IP в ipset vpn1».

ipset `vpn1` прописан в iptables как: «любой TCP пакет к IP из vpn1 → redirect на порт 1080 (Xray)».

| Шаг | Что делать | Как |
|-----|-----------|-----|
| 1 | Установить всё одной командой | `curl ... \| sh` из SSH |
