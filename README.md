# keenetic-xray-vpn

Веб-интерфейс для Xray VPN-клиента на роутерах Keenetic с Entware. Маршрутизирует трафик через VPN на основе доменов (через AdGuard Home + ipset), IP/подсетей, списков v2fly или MAC-адресов устройств. Поддерживает несколько серверов одновременно и **маршрутизацию по правилам**: каждый домен/IP/список можно направить через выбранный сервер, через конкретный сервер или напрямую (в обход VPN). Поддерживает VLESS Reality, Shadowsocks, опциональный WireGuard-сервер.

## Установка одной командой

Подключись к роутеру по SSH (с включённым Entware) и запусти:

```sh
curl -fsSL https://github.com/Aynur-coder/keenetic-xray-vpn/releases/latest/download/install.sh | sh
```

Эта ссылка **всегда** скачивает последнюю стабильную версию.

После завершения открой **http://192.168.1.1:91** — мастер настройки проведёт за 5 шагов:

1. Пароль веб-UI (для доступа извне локальной сети).
2. Пароль admin Keenetic (для получения списка устройств через RCI).
3. URL первой подписки.
4. Выбор активного сервера.
5. Включение/отключение WireGuard.

После мастера: открой **http://192.168.1.1:3000** (AdGuard Home), задай пароль и upstream DNS в его мастере.

## Правила маршрутизации

Раздел **«Правила»** объединяет домены, IP и списки v2fly в один список с фильтрами (Все / Домены / IP / Списки v2fly), поиском и массовыми операциями (выделение галочками, смена подключения у нескольких сразу, удаление выбранных).

Для каждой записи можно выбрать **подключение**:

- **Прокси (активный)** — через текущий выбранный сервер (поведение по умолчанию, как у всех существующих записей);
- **конкретный сервер** — например, один домен через сервер в США, другой через Сингапур;
- **Напрямую** — полный обход VPN (трафик вообще не заходит в Xray).

Для доменов можно выбрать тип совпадения: **Поддомены** (домен и все поддомены) или **Точный** (только указанный домен).

Несколько важных моментов:

- Смена сервера у домена/IP применяется **мгновенно** (перезапускается только Xray, ~1с); список перенаправления и AdGuard не трогаются.
- **Приоритет v2fly:** если домен есть во включённом v2fly-списке, отдельная ручная копия считается лишней и убирается — кроме случая, когда у неё задано особое подключение (тогда это осознанное исключение, помечается бейджем). Кнопка **«Убрать дубли»** делает разовую чистку.
- Разделение по серверам происходит **внутри Xray**, поэтому нагрузка на роутер почти не растёт: один и тот же ipset, те же правила iptables.

Совместимость полная: после обновления все существующие домены/IP/списки продолжают работать через активный сервер; исключения хранятся в `rules/rule_targets.json`.

## Обновление

В UI: иконка обновления (или шестерёнка → «Проверить обновления») → «Обновить». Окно показывает текущую версию, доступное обновление и раздел «История изменений» со всеми версиями.

Обновление кода идёт быстро и **не перезапускает** AdGuard/Xray (VPN не отваливается), а апдейтер полностью отсоединяется от веб-сервера (`setsid`) — поэтому процесс больше не «зависает» в статусе `applying`.

Из SSH:

```sh
/opt/etc/xray/update.sh --apply
```

Автообновление можно включить в настройках (cron каждый день в 04:30).

## Удаление

```sh
curl -fsSL https://github.com/Aynur-coder/keenetic-xray-vpn/releases/latest/download/install.sh | sh -s -- --uninstall
```

## Требования

- Роутер Keenetic с прошивкой 4.x или 5.x.
- Entware установлен на USB-носителе (`/opt`).
- ≥20 MB свободного места в `/opt`.
- Подключение к интернету для скачивания пакетов.

Поддерживаемые модели (протестировано): Keenetic Hopper (KN-3810). Другие модели на той же архитектуре должны работать — пиши в Issues, если столкнулся с проблемой.

## Безопасность

- Веб-UI без пароля только из локальных сетей (`192.168.1.0/24`, `10.50.0.0/24`).
- Удалённый доступ к UI требует пароль (sha256+salt).
- Пароли хранятся с `chmod 600` от root.
- HTTPS не предоставляется — для внешнего доступа рекомендуется WireGuard-туннель к роутеру.

## Что под капотом

| Компонент | Назначение |
|---|---|
| Xray-core | VPN-клиент (VLESS, SS, Trojan) |
| AdGuard Home | DNS-маршрутизация (какие домены идут через VPN) |
| WireGuard | Опциональный VPN-сервер для клиентов |
| lighttpd + php-cgi | Веб-сервер для UI на порту 91 |
| ipset + iptables | Firewall-маркировка трафика |
